SOBRE

Sobre o projeto

O SkyTime é uma aplicação web desenvolvida em JavaScript que integra APIs em tempo real para oferecer previsões meteorológicas detalhadas e as últimas notícias do Brasil. O objetivo é reunir informação útil e atualizada numa interface simples, rápida e intuitiva..
